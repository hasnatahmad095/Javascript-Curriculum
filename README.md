# Javascript-Curriculum

A compact, file-based curriculum to learn core JavaScript concepts. Each lesson is a standalone HTML file you can open directly in your browser. Follow the numbered order for a smooth progression from basics to DOM/BOM and practice exercises.

## How to use
- Open any lesson by double-clicking the corresponding `.html` file, or open it in your editor and use a live server extension.
- Start from lesson 1 and proceed in order. Practice and exercise files are interleaved to reinforce topics.
