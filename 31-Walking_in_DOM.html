Walking in the DOM

DOM refers to the HTML page where all the nodes are objects. There can be three main types of nodes in the tree:

  • Text Node
  • Element Node
  • Comment Node

In an HTML page, HTML is at its root and head & body are its children. A text node is always a leaf of the tree.

  • Auto Correction [if there is missing tag or something out of the body then it will automatically moves in the body]

  • document.title() returns string, while document.body(), document.head(), returns object.
